
# 📁 Folder Overview

This folder contains the scripts to compare the results obtained with the MOD algorithm on the numerical test cases among different level of prior knowledge of the system.

---

## 📂 Folder Structure

### 📊 Results Folders

- **`results_on_trajectories/`**
  These folder contains the coverage proportions on OOD trajectories obtained with the MOD algorithm with different level of prior knowledge.

- **`results_on_vector_field/`**  
  These folder contains the coverage proportions on OOD points of the state space obtained with the MOD algorithm with different level of prior knowledge.

---

## 📈 Comparison scripts

- `comparison_results_on_trajectories.jl`  
  Main scripts to compare the coverage proportions on trajectories.

- `comparison_results_on_vector_field.jl`  
  Main scripts to compare the coverage proportions on vector field.
