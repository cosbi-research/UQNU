
# 📁 Folder Overview

This folder contains the scripts to run the MOD algorithm on the Computational Biology test case.

---

## 📂 Folder Structure

### 📊 Folders

- **`UDE_training/`**
  These folder contains the code to train standard ensembles.

- **`MOD_UDE_training/`**  
  These folder contains the code to train MOD ensembles and to analyze the results - comparing the results obtained with MOD ensembles and standard ensembles on the cell survival scenario.

- **`data_generator/`**  
  These folder contains the code generate the training set (in the cell death scenario) used to train both standard and MOD ensembles.

- **`cell_apoptosis_settings/`**  
  These folder contains the settings used to simulate the cell apoptosis model.

## 🧬 Project Metadata

- `Manifest.toml`  
- `Project.toml`  
  Julia environment files specifying project dependencies and versions.
